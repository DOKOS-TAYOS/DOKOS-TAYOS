## Qué encontrarás aquí

Este perfil es el mapa público de mi trabajo. Aquí conviven repositorios de investigación, software científico reutilizable, material docente y experimentos pequeños que a veces terminan creciendo hasta convertirse en herramientas mayores.

Trabajo sobre todo donde se cruzan tensor networks, algoritmos cuánticos, métodos numéricos y Scientific Python práctico. Me interesa que las ideas avanzadas se puedan ejecutar, inspeccionar, visualizar y explicar.

<a id="research-in-code"></a>
## Investigación en Código

Estos repositorios están conectados directamente con papers, experimentos e ideas algorítmicas en las que he trabajado:

- [TSP with Tensor Networks](https://github.com/DOKOS-TAYOS/Traveling_Salesman_Problem_with_Tensor_Networks) - solver del problema del viajante inspirado en ideas cuánticas. [Paper](https://arxiv.org/abs/2311.14344)
- [HHL with Tensor Networks](https://github.com/DOKOS-TAYOS/Tensor_Networks_HHL_algorithm) - simulación clásica del algoritmo HHL. [Paper](https://arxiv.org/abs/2309.05290)
- [Linear Chain QUBO and QUDO](https://github.com/DOKOS-TAYOS/Lineal_chain_QUBO_QUDO_TensorQUDO_Solver_with_Tensor_Networks) - solver polinómico para QUBO tridiagonal, QUDO y Tensor QUDO. [Paper](https://arxiv.org/abs/2309.10509)
- [Efficient Tensor Network Initialization](https://github.com/DOKOS-TAYOS/Efficient_Initialization_Tensor_Networks) - inicialización finita con normas parciales para tensor neural networks. [Paper](https://arxiv.org/abs/2309.06577)
- [Task Scheduler with Tensor Networks](https://github.com/DOKOS-TAYOS/Task_Scheduler_with_Tensor_Networks) - optimización de planificación mediante métodos de tensor networks. [Paper](https://arxiv.org/abs/2311.10433)
- [HoLCUs + QAOA](https://github.com/DOKOS-TAYOS/HoLCUs_QAOA) - experimentos con HoLCUs conectados con QAOA. [Paper](https://arxiv.org/abs/2503.01748)
- [Hotels-TSP-Tensor-QUDO](https://github.com/DOKOS-TAYOS/Hotels-TSP-Tensor-QUDO) - TSP estilo buscador de viajes explorado con formulaciones QAOA, QUBO y Tensor QUDO
